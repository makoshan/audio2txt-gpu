最小可落地代码

🐍 faster-whisper · Colab / Studio Lab 通用
# Step 1: 安装
!pip install -q faster-whisper

# Step 2 (仅 Colab): 挂载 Drive
from google.colab import drive
drive.mount('/content/drive')

# Step 3: 转录
from faster_whisper import WhisperModel, BatchedInferencePipeline

model = WhisperModel("large-v3", device="cuda", compute_type="float16")
batched = BatchedInferencePipeline(model=model)

segments, info = batched.transcribe(
    "/content/drive/MyDrive/audio.mp3",  # ← 改成你的路径
    batch_size=16,
    vad_filter=True,
    word_timestamps=True,
    language="zh"
)

# Step 4: 输出
for seg in segments:
    print(f"[{seg.start:.1f}s → {seg.end:.1f}s] {seg.text.strip()}")
📦 WhisperX · 说话人分离扩展（按需）
!pip install -q whisperx

import whisperx

HF_TOKEN = "hf_你的token"  # huggingface.co/settings/tokens
audio = whisperx.load_audio("/content/drive/MyDrive/audio.mp3")

# 1. 转录
model = whisperx.load_model("large-v3", "cuda", compute_type="float16")
result = model.transcribe(audio, batch_size=16, language="zh")

# 2. 词级对齐
align_model, metadata = whisperx.load_align_model(language_code="zh", device="cuda")
result = whisperx.align(result["segments"], align_model, metadata, audio, "cuda")

# 3. 说话人分离
diarize = whisperx.DiarizationPipeline(use_auth_token=HF_TOKEN, device="cuda")
result = whisperx.assign_word_speakers(diarize(audio), result)

for seg in result["segments"]:
    print(f"[{seg.get('speaker','?')}] {seg['text'].strip()}")
🖥️ 本地命令行（transcribe.py）
# 安装
pip install faster-whisper

# 基础转录
python transcribe.py meeting.mp3

# 指定模型和语言
python transcribe.py meeting.mp3 --model turbo --lang zh

# 输出到指定目录
python transcribe.py meeting.mp3 --model large-v3 --out-dir ./output

# 切换到 Studio Lab 时只需改路径
# AUDIO_PATH = '/home/studio-lab-user/audio.mp3'

调研中发现的旧方案问题

⚠️ 你原始链接里的 notebook 不建议直接用

🔴 旧版 錄音檔轉文字.ipynb — 核心是 SpeechRecognition 库，不是 Whisper，也没有用 GPU。作者自己在 2024-02-20 更新记录里写明 Colab 多线程被限制后方案已变脆弱。

🔴 colab-cli（Akshay090） — 最后提交是 2020-04-27，仅 21 次提交，主要功能是同步本地 .ipynb 到 Drive，不能控制 Colab runtime。

🟡 googleworkspace/cli — 活跃（最近提交 2026-03-26），但它是 Workspace API CLI，不是 Colab runtime 控制器，最多帮你操作 Drive 文件，不能替代 Colab 本身。
